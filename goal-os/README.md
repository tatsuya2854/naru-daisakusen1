# Goal OS — 自分用の行動OS（目的 → ゴール → ToDo）

サブスクなしで自分だけが使う目標管理アプリ。`index.html` 1枚だけ。
サーバー不要・アカウント不要・データは全部ブラウザの `localStorage`。

## 使い方

- **ローカル**: `goal-os/index.html` をブラウザで開くだけ。
- **スマホ**: GitHub Pages を有効にすれば `https://<user>.github.io/naru-daisakusen1/goal-os/` で開ける。
  Safariの共有 →「ホーム画面に追加」でネイティブアプリっぽく全画面起動する。

## 画面

| タブ | 中身 |
|---|---|
| 今日 | 今日やる上位N件を自動抽出（フォーカス）。連続記録・完了数・平均進捗。期限超過の一括引き直し。 |
| マップ | 目的 → ゴール → ToDo のマインドマップ。ドラッグで移動、ピンチ/ホイールで拡大、ノードをタップで編集。 |
| ゴール | 進行中／達成／停止で切り替え。進捗バー、期限、ペース判定、停滞日数。 |
| ふりかえり | 8週間の実行ヒートマップ、前週比、遅れてるゴール順の一覧、日次メモ。 |

## 自動で「今日の一手」を決めるロジック

各ToDoにスコアを付けて上位を出す（`score()`）:

- 期限までの近さ（超過 > 今日 > 明日 > …）
- ToDo自体の優先度
- 習慣（繰り返し）は毎日積む前提で加点
- **ひもづくゴールの遅れ具合**（期待進捗 − 実進捗）
- **ゴールの停滞日数**（最後に前進してからの日数）

単なる期限順ではなく、ゴール側の状態がToDoの順位に効くのがポイント。

## AI分解（任意）

4つのモード: ①漠然とした願望 → 目的/ゴール/ToDoに分解 ②既存ゴールをToDoに分解
③停滞ゴールの立て直し案 ④今日の優先順位づけ。

使い方は2通り。どちらでも全機能使える。

1. **APIキーを入れる**: 設定 → Anthropic APIキー（`sk-ant-…`）。ブラウザから直接
   `api.anthropic.com/v1/messages` を叩く（`output_config.format` の JSON Schema で構造化出力）。
   キーはこの端末の localStorage にだけ保存。従量課金なので月額サブスクより基本安い。
2. **キー無しで手動**: 「プロンプトをコピー」→ 普段使ってるClaudeに貼る →
   返ってきたJSONを貼り戻す。追加コスト0円。

どちらもプレビューを見てから「反映する」を押すまでデータは変わらない。

## データ

- 保存先: `localStorage['goalos.v1']`
- 設定 → 「バックアップを書き出す」で JSON エクスポート、「読み込む」でインポート。
- **キャッシュ削除や機種変で消える**ので、たまに書き出しておくこと。
